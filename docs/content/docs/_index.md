fgraph is an embedded temporal fact store: immutable facts `⟨entity, attribute, value⟩` in one SQLite file, with full history, provenance, Datalog queries, and hybrid search. Start with [Getting Started](getting-started), understand the model in [Concepts](concepts), then wire it into your agents in [Integrations](integrations).
